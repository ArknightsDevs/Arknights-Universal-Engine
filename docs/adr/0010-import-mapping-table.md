# 0010 导入路径映射表是唯一事实来源

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q33, Q42

## 背景

要兼容的 Stronghold kit 用它自己的导入路径。同一份内容要在 Node、主线程调试和后台线程里加载。如果每处各写一套重写规则，会漂移。

## 决定

- Stronghold kit 的导入路径映射到我们的模块，写在一张映射表里。
- 由这张表生成三样东西：
  - Node 的加载钩子（`module.register`）；
  - 主线程调试用的 import map；
  - 后台线程的构建产物（构建时改写导入路径，由 `@aue/worker` 完成）。
- 不修改 kit 的源码，只改写导入路径。

## 理由

单一来源，三处行为一致；适配层集中，Stronghold 接口变化时只改一处。

## 后果

- 映射表生成器是起步里程碑的交付之一。
- Stronghold 的接口在变，要固定版本，修复回馈上游。
- 脚本 mod 同样用这张表改写，见 [0038](0038-script-mod-rewriting.md)。
