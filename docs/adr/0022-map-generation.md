# 0022 地图按关卡数据生成

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q12, Q59

## 背景

合作关卡没有可直接使用的原版场景素材。要在没有场景文件的情况下画出像原版的地图。

## 决定

- 地图按关卡数据生成：
  - 地块按高度和可部署类型，用原版主题的材质拼出来；
  - 出入口和合作模式专用的地块、特效、装置，用合作专用素材；
  - 光照用实时光近似，因为没有烘焙的光照贴图；
  - 周边装饰先不做，或者由 mod 提供背景；
  - 用能找到的官方截图校验观感。
- mod 可以提供背景（见 [0039](0039-mod-assets.md)）。
- 坐标和镜头见 [0026](0026-camera-model.md)。

## 理由

关卡数据是确定可得的；场景文件不可得。按数据生成，所有关卡都能用，也方便 mod 扩展。

## 后果

- 生成的地图可能不像原版。应对：用原版主题材质和合作专用素材，截图校验，mod 可换背景。
- 没有烘焙光照，观感会有差距。
