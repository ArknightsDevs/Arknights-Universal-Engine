# 0021 界面：战斗界面按原版还原，战斗外界面自己设计

- 状态：已取代（被 [0063](0063-coop-lobby-ui-restoration.md) 取代）
- 日期：2026-10-11
- 来源：规划讨论 Q60

## 背景

战斗界面要和原版一致。战斗外的界面（大厅、匹配、房间）没有原版可还原，而合作模式有自己的界面插件。

## 决定

- 战斗界面从原版的 Unity 界面预制件还原，用争锋频道的 UI 引擎（搬进引擎成为 `@aue/ui`）。包括合作模式的界面插件。
- 战斗外的界面（大厅、匹配、房间）按活动风格自己设计，用原版的活动图片和载入图。
- 没实现的系统不留空洞：界面里不放不能用的入口。
- 素材由维护者另行准备并放在独立的素材仓库（见 [0018](0018-asset-repository-and-hosting.md)）。

## 理由

- 战斗界面信息量大、对操作影响大，还原原版最稳妥。
- 战斗外没有可还原的依据，自己设计比猜测更诚实。

## 后果

- `@aue/ui` 要持续补齐预制件功能。
- 战斗外的界面是原创设计，风格要和原版协调。
- 顶栏、部署卡、费用条用 `@aue/ui` 画在页面上；血条、方向选择器、干员菜单作为叠加层，见 [0027](0027-occlusion-draw-order.md)。
