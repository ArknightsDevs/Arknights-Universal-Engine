# 0001 定位：做成平台，官方内容优先，PC 优先

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q1, Q3, Q25

## 背景

我们要做一个明日方舟战斗引擎，第一个玩法是双人实时合作（促融共竞）。如果只为这一个玩法写死，以后加足球、堡垒守御、漂航等模式都要重来。

本项目是非官方同人项目，与鹰角网络、悠星无关，源自《明日方舟》，禁止商用。

## 决定

- 做成平台：通用引擎 + 玩法插件 + 大厅、账号、存档、活动框架。
- 引擎叫 Arknights Universal Engine / 明日方舟通用引擎（AUE），是确定性、帧同步、浏览器 + Node 的战斗引擎。
- 内容以官方内容优先：干员、敌人、关卡、技能先用官方数据，再谈自制内容。
- 手机和 PC 都支持，PC 优先。

## 理由

- 玩法规则放进插件，内核不变，后续模式的成本低。
- 官方内容覆盖面大，玩家熟悉，也最容易对照原版验证。
- 手机性能和显存是风险，但不能因此放弃手机端。性能预算在渲染里程碑里实测后再定（见 [0051](0051-mvp-scope-and-milestones.md)）。

## 后果

- 内核要提供多玩家等通用能力，玩法差异放进插件（见 [0015](0015-multiplayer-in-core.md)）。
- 要同时维护引擎、平台、素材三类产物（见 [0002](0002-repository-split.md)）。
- PC 优先意味着界面和操作先按 PC 设计，手机端后补，可能有体验差距。

## 备选方案

- 只做促融共竞一个游戏：否决，后续模式要重写。
