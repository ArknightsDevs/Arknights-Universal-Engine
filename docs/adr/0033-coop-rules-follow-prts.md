# 0033 合作模式规则照 PRTS，没有数字的先推断并登记

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q31, Q52

## 背景

促融共竞没有官方的公开规则文档。[PRTS](https://prts.wiki/w/促融共竞) 有玩家整理的规则。有些数字（标记数量、标记冷却）PRTS 也没有给。

## 决定

- 合作模式规则全部照 PRTS。
- PRTS 没给数字的，比如标记数量、标记冷却，先按推断取值，登记出来，写明依据（见 [0043](0043-ci-gates-and-registry.md)）。
- 掉线：一方掉线时，他的干员继续作战；双方都掉线，战斗暂停。
- 延迟超过 200 ms 时提示网络不适合。
- 没有慢放（见 [0032](0032-command-table.md)）。
- MVP 只做常规项目（见 [0051](0051-mvp-scope-and-milestones.md)）。
- 玩家、复活、费用转移等通用能力在内核，目标和计分在插件（见 [0015](0015-multiplayer-in-core.md)）。

## 理由

PRTS 是目前最完整的公开来源。推断登记在册，有了证据再改，不会悄悄固化。

## 后果

- 推断的数字可能和原版不一致。
- PRTS 页面会变，引用要带固定版本（oldid）。
