# 0016 任意练度在数据层计算

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q28

## 背景

玩家的干员练度各不相同（等级、精英化、潜能、技能等级等），box 录入后要按玩家自己的练度对战（见 [0036](0036-box-entry-and-import.md)）。有些 Stronghold kit 把练度写死了。

## 决定

- 任意练度在数据层计算，生成对应练度的数值，再交给模拟。
- 写死了练度的 kit 做适配。
- 修复方案回馈 Stronghold 上游。

## 理由

练度计算是纯数据变换，放数据层，模拟内核不用关心练度。

## 后果

- 数据层要实现练度到数值的完整计算，并计入数据哈希。
- 适配改动要维护，并向上游提交。
