# 0062 发布包附带素材和 kit

- 状态：已采纳
- 日期：2026-10-16
- 来源：维护者 2026-10-16 决定（照 Stronghold Protocol 的做法，把素材直接放进 Release）

## 背景

[0018](0018-asset-repository-and-hosting.md) 让开服的人自己取得固定版本的素材再提供给玩家，[0058](0058-stronghold-kits-in-matches.md) 让服务器安装时自己取 kit。这样开服要好几步。Stronghold Protocol 的做法是在 GitHub Releases 里附带完整包：程序、运行依赖和素材都在里面，解压即可开服，素材的使用条件写在包里的 NOTICE 中。

## 决定

- 平台每个版本在 GitHub Releases 附两个包，由维护者用自己的账号发布：
  - **完整包**：程序、运行依赖、素材、固定提交的 kit、启动脚本，以及列出每个文件大小和 sha256 的清单。装好 Node.js 后解压即可开服。
  - **素材包**：只有素材和清单，给从源代码运行的服务器用。
- 公开仓库仍然不收录素材，也不收录 kit 的源码。素材仍由维护者另行准备，导出工具不公开。
- 包里的素材附带 NOTICE：素材版权归上海鹰角网络与悠星，不在代码许可范围内，仅限非商业用途，不得用于本项目以外的用途，也不得单独再分发；下载即视为同意。来自公开仓库的素材列出来源和固定提交。
- 完整包里的 kit 是 Stronghold Protocol 固定提交的原文件，带上它的许可和版权声明，并写明完整源码的位置，遵守 GPL-3.0-or-later。
- 打包工具在打包前检查：拒绝名单、符号链接、只差大小写的路径、个人信息（本机路径、账号名、邮件地址）。包里带校验脚本，按清单核对每个文件。
- [0018](0018-asset-repository-and-hosting.md) 的其余决定不变：素材仓库独立，按版本固定，清单列出哈希，素材地址可配置。开服的人仍然可以自己提供素材（`AUE_ASSETS_DIR`）和 kit（`AUE_KITS_DIR`）。

## 理由

开服一步到位，玩家和开服的人不需要导出工具，也不需要自己找素材。素材的使用条件随包分发，和 Stronghold 一样明确。

## 后果

- 每次发布要用素材仓库的固定版本重新打包，包约 245 MB。
- 维护者准备的素材（战斗界面、特效、音效、地块套件等）随 Release 公开下载，发布前要再确认一遍 NOTICE。
- 包里的 kit 随引擎固定的提交走，引擎换提交时要重新打包。
