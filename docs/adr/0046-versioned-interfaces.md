# 0046 接口有版本，用契约测试检查

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q72

## 背景

模块之间、客户端和服务器之间、引擎和平台之间有多个数据接口。接口悄悄变化，会让断同步或加载失败难以追查。

## 决定

下列每样都有带版本号的模式定义和固定的样例数据，用契约测试检查：

- 渲染状态缓冲区；
- 表现事件；
- 网络协议；
- 快照；
- mod 清单；
- 素材清单。

## 理由

版本号让不兼容的两端能在握手时发现，样例数据让改动对契约的影响在 CI 里可见。

## 后果

- 每次改接口要同时改模式、样例和契约测试。
- 第一版接口模式在端到端骨架里定型（见 [0050](0050-end-to-end-skeleton-first.md)）。
