# 0018 素材：独立素材仓库，开服时下载固定版本并自己提供

- 状态：已取代（被 [0062](0062-release-bundles-with-assets.md) 取代）
- 日期：2026-10-11
- 来源：规划讨论 Q11, Q21, Q24, Q62

## 背景

素材版权归鹰角，不属于代码许可范围，体积也大。但战斗要用原版样式的素材（见 [0025](0025-true-3d-three-js.md)）。

## 决定

- 素材由维护者另行准备，放在独立的素材仓库；导出工具不公开。
- 素材仓库放转换后的素材：Spine、特效、地图主题、界面预制件和图片、音频。只放支持的内容。
- 按版本打标签，清单里列出每个文件的哈希。
- 素材版权归鹰角；NOTICE 写明素材不在代码许可范围内。
- 主机启动时下载固定版本的素材，自己提供给玩家。
- 素材地址可配置，可以换成自建 CDN。
- 客户端校验哈希。

## 理由

- 独立仓库让许可和体积都清楚。
- 固定版本加哈希校验，保证两端用同样的素材，也防止下载被篡改。
- 可配置地址让开服的人自己决定分发方式。

## 后果

- 公开仓库只含代码，不含游戏素材，也不含导出工具。
- 素材仓库名称还没定。
- 服务器要有素材服务（下载并提供固定版本的素材）。
