# 0034 战斗外的活动系统：照做、改动、全部解锁

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q57

## 背景

促融共竞在战斗之外还有房间、匹配、难度解锁、比赛风格、个人资料等系统。我们不发放游戏道具和货币，也没有账号体系可以依赖（见 [0035](0035-saves-and-accounts.md)）。

## 决定

照做：

- 房间：房间号、邀请，15 分钟后关闭；
- 随机匹配，分常规、教练、学员三种身份；
- 互选模式、训练场；
- 初级、进阶、特别三档难度，靠嘉奖印章解锁；
- 比赛风格：每 10 枚印章得一本指南，用来解锁一种风格；
- 个人资料：称号的前缀和后缀、名片、点赞、指导次数；
- 个人最佳。

改动：

- 去掉发游戏道具和货币的奖励；
- 里程任务和热度等级保留，只用来显示进度、解锁称号和名片。

主机选项："全部解锁"。

时间安排：MVP 只做局域网房间，所有比赛风格都能选；进度系统放在账号系统之后。

## 理由

保留玩法上有意义的部分，去掉与真实经济挂钩的部分，符合非商用的定位。

## 后果

- MVP 里没有进度系统，"全部解锁"是默认可用的出路。
- 进度系统依赖账号和存档，时间上在其后。
