# 0063 促融共竞的战斗外界面也按原版还原

- 状态：已采纳
- 日期：2026-10-16
- 来源：维护者 2026-10-16 决定（战斗外界面接入原版，v0.1.0 推迟到接完一起发）

## 背景

[0021](0021-battle-ui-restoration.md) 让战斗界面按原版还原，战斗外的界面（大厅、匹配、房间）自己设计，理由是战斗外没有可还原的依据。现在促融共竞战斗外界面的原版预制件和动画片段已经可以取得：活动主界面、房间与赛前流程的各步骤、赛前编队与比赛风格、结算。

## 决定

- 促融共竞的战斗外界面也从原版的界面预制件还原，用 `@aue/ui` 绘制和播放动画，包括：
  - 活动主界面：创建、加入房间（输入房间编号）。
  - 房间与赛前流程：步骤倒计时、双方玩家信息、项目调整与项目确认、关卡确认与开赛展示、编队检查与干员分配、高顺位干员的轮流选取、组建上场阵容（技能、模组）、开赛倒计时。
  - 赛前编队与比赛风格。
  - 结算、断线提示、对话框与提示。
- 页面逻辑照我们自己的房间流程（平台的 房间-1…6），原版界面只负责画面和动画。原版界面的状态机不照搬。
- 原版没有对应界面的部分，继续按活动风格自己设计：干员 box 录入与本地存档、画面设置、局域网说明。
- 没有对应系统的界面不做，入口也不显示（沿用 0021「不留空洞」）：快速匹配、手册（照片、称号、任务）、训练、里程碑与奖励。
- 活动主界面的 3D 场景用 three.js 绘制，和战斗用同一套渲染；先做平面部分，再做 3D。
- 战斗界面照旧按原版还原。素材由维护者另行准备（见 [0018](0018-asset-repository-and-hosting.md)、[0062](0062-release-bundles-with-assets.md)）。

## 理由

有了原版依据，还原比自己设计更接近原作，也和战斗界面一致。页面逻辑照自己的房间流程写，是因为局域网对局、本地存档这些系统和原版不同。

## 后果

- `@aue/ui` 要补滚动列表、嵌套预制件、自适应字号、屏幕适配、输入框、界面粒子等能力。
- 平台的房间页改为原版界面；没有素材时仍然用现在的简易页面。
- 发布包变大，需要补齐界面用的字体。
