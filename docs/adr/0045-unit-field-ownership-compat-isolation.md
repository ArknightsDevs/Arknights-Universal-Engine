# 0045 单位字段归属表与兼容层隔离

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q72

## 背景

Stronghold 的单位有 129 个字段，任何模块都能读写，难以追踪谁改了什么。兼容代码如果渗入内核，会让内核继承外部接口的包袱。

## 决定

单位字段：

- 按组分好，写明类型。
- 另有一张归属表，规定哪个模块可以写哪个字段，用自写的 ESLint 规则检查。
- 从 Stronghold 搬来的 kit 为了兼容，不受这条约束。

兼容层隔离：

- Stronghold 的兼容代码只放在 `@aue/content/compat/`。
- 内核不许导入它（用导入规则强制，见 [0008](0008-module-boundaries.md)）。

## 理由

写入权限明确，就能定位状态变化的来源；兼容层隔离，内核才能独立演进。

## 后果

- 内核字段与兼容接口的 129 个字段之间需要转换层。
- 字段归属表要随内核演进维护。
- 兼容接口本身见 [0012](0012-stronghold-compatible-core.md)。
