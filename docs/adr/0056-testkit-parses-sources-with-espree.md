# 0056 testkit 用 espree 解析源码

- 状态：已采纳
- 日期：2026-10-12
- 来源：M4 兼容层准备（kit 的 `COLS` / `ROWS` 用法分析）

## 背景

兼容层要知道 Stronghold kit 在哪里读 `COLS`、`ROWS`：在函数里读（每次调用时读到当时的值），还是在模块加载时就读（值被固定下来）。用正则按行判断分不清箭头函数和顶层表达式，容易误判。

## 决定

- `@aue/testkit` 依赖 espree（固定 11.2.0），用它把源码解析成语法树来分析。
- espree 是 ESLint 自带的解析器，已经在依赖树里；这里只是把它写成 testkit 的直接依赖，不引入新的第三方包。
- 只用于开发期的检查和测试，不进入任何运行时包。

## 理由

语法树能准确区分「在函数体内」和「在模块顶层」，分析结果才能作为测试的依据。

## 后果

- `tools/layers.json` 中 testkit 的允许列表加上 espree。
- 升级 ESLint 时一并核对 espree 的版本。
