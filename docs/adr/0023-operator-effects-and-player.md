# 0023 干员特效：MVP 做攻击、命中和常见状态，技能特效分批

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q62, Q63

## 背景

干员的攻击和技能都挂着特效，数量很大。争锋频道里已经有一个原版特效播放器，用的是 Pixi 和近似透视。

## 决定

- 素材准备流程扩展到干员特效；导出工具不公开，结果放进素材仓库（见 [0018](0018-asset-repository-and-hosting.md)）。
- MVP 包括攻击、命中和常见状态特效；技能特效在 MVP 之后分批加入。
- 缺素材时用官方的通用特效顶替，绝不显示没有贴图的东西。
- 把争锋频道的特效播放器从 Pixi 移植到 three.js：
  - 它已经支持粒子、拖尾、子发射器、碰撞平面、动画轨道，以及溶解、扰动、相乘等着色器；
  - 在争锋频道里它用近似透视，这次改用真实镜头；
  - 争锋频道还没做完的部分移植后继续补：跟随挂点、第二次溶解、第二次扰动、遮罩叠加贴图、非出生时触发的子发射器。
- 特效不写深度，前后顺序按排序值（见 [0027](0027-occlusion-draw-order.md)）。

## 理由

- 先做攻击、命中，玩家最常看到，价值最高。
- 复用已有播放器，只换渲染后端。

## 后果

- 技能特效在 MVP 里缺失，要靠通用特效顶替。
- 特效数量要设上限，保护手机性能。
