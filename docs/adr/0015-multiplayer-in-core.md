# 0015 多玩家能力放进内核，玩法规则放进插件

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q43

## 背景

合作模式需要多个玩家各有部署区、费用和生命。以后的堡垒守御、足球、漂航也要复用这些能力，但规则各不相同。

## 决定

内核提供：

- 多个玩家，各自有部署区、费用、生命和目标点；
- 单位归属；
- "共同敌手"标记：带标记的敌人进点时，两个玩家都扣生命；
- 阵亡和复活计时：生命归零后不能部署、干员停止工作；30 秒后，如果自己的目标点上没有敌人就复活，有敌人进入就重新计时；
- 费用转移。

常规项目插件负责：

- 关卡目标（生存、救援、清除、刺杀、突击、占领、护送）；
- 一局两关的流程（关与关之间重置血量、复活、撤退和冷却）；
- 嘉奖印章计分，死亡两次扣印章；
- 比赛风格的加成、代价和装置。

以后的堡垒守御、足球、漂航只写插件，内核不变。漂航模式按官方常数做物理，是唯一会改变模拟语义的地方。

## 理由

玩家、归属、复活这类能力各模式都要，放内核复用；关卡目标和计分因模式而异，放插件。

## 后果

- 内核的快照、状态哈希要覆盖多玩家状态。
- 插件接口要有版本（见 [0046](0046-versioned-interfaces.md)）。
- 规则细节依 PRTS，没给数字的先推断（见 [0033](0033-coop-rules-follow-prts.md)）。
