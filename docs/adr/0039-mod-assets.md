# 0039 mod 素材：允许的格式、哈希清单、大小上限、严格解析

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q70

## 背景

mod 带来的素材是不可信输入，由主机提供给所有玩家。格式要限定，加载要安全。

## 决定

- 允许的素材：
  - Spine 3.8；
  - 我们格式的特效 JSON；
  - glTF 2.0（`.glb`）背景；
  - WebP / PNG 图片；
  - Ogg Opus 音频。
- 数据 mod 不能带脚本。
- 清单里列出每个文件的哈希，由主机提供，客户端逐个核对。
- 单个文件和整个包都有大小上限。
- 所有素材用严格解析器读取，不执行。

## 理由

限定格式，才能限定解析器的攻击面；哈希清单保证各端一致。

## 后果

- 其他格式的素材需要 mod 作者先转换。
- 大小上限的具体数值需要实测后确定。
- 若引入 KTX2（见 [0020](0020-texture-format-webp.md)），允许格式要相应更新。
