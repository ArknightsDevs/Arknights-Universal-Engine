# 0049 决定记录为 ADR，改决定就新增一条

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q72

## 背景

早期的决定集中写在一份规划文档里，改动不留痕迹，也难以按主题查阅。

## 决定

- 决定拆成 `docs/adr/` 下的架构决定记录，每个主题一条。
- 改决定就新增一条，把旧的标为「已取代」，两边互相链接；不静默修改已采纳的决定。
- 规划文档作为历史保留，不再更新。
- 做法见 [README](README.md)，模板见 [0000](0000-template.md)。

## 理由

每条决定有日期、来源、理由和后果，变更可追溯。

## 后果

- 改决定要多写一条记录。
- 索引要同步更新。
