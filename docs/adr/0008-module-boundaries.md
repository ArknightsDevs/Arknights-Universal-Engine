# 0008 模块边界由 lint 的导入规则强制

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q46, Q72

## 背景

模拟必须确定、可在 Node 和后台线程里跑；渲染、界面、网络依赖浏览器或 GPU。边界靠约定很容易被破坏。

## 决定

- `sim` 不能导入 `render`、`ui`、`net`。
- `render` 只能读模拟的输出（渲染状态缓冲区和表现事件），不能改模拟状态。
- 以上用 ESLint 的导入规则强制，进 CI。
- 另有模拟代码的确定性禁令：禁止 `Math.random`、`**` 和不精确的 `Math` 函数（见 [0011](0011-numerics-integer-frames.md)）。

## 理由

边界进 CI 才不会被悄悄破坏；这也是 `sim` 能在 Node、后台线程、服务器复算中保持一致的前提。

## 后果

- 需要维护一套自写 lint 配置。
- 跨边界的数据只能走带版本的接口（见 [0046](0046-versioned-interfaces.md)）。
