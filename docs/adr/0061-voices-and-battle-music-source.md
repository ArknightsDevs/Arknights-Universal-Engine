# 0061 战斗语音和缺的战斗曲来自 ArknightsAssets2，固定提交，进入 v0.1.0

- 状态：已采纳
- 日期：2026-10-16
- 来源：规划讨论 Q69；维护者 2026-10-16 决定语音进入 v0.1.0

## 背景

[0024](0024-audio-sources.md) 让 MVP 里干员没有语音，关卡自己的战斗曲缺着时用默认战斗曲，等 MVP 之后从公开来源补。现在维护者决定语音进入 v0.1.0，所有规则照官方数据。

## 决定

- 干员战斗语音和关卡缺的战斗曲取自 [ArknightsAssets/ArknightsAssets2](https://github.com/ArknightsAssets/ArknightsAssets2) 的 `voice` 分支，固定到提交 33a5327（2026-10-09）。文件原样进素材仓库（见 [0018](0018-asset-repository-and-hosting.md)），逐个按该提交的 git 树核对哈希。
- 语音的台词、配音语言、默认配音、触发类型的优先级、冷却和交叉淡化，全部取自游戏数据（`charword_table.json`、`audio_data.json` 的 `battleVoice`）。数据没写的部分（触发时机、类型与台词的对应、排队方式）登记为推断（见 audio.md 音频-4…6）。
- 素材默认带中文-普通话、日语和联动配音（数据里的默认配音是日语和联动），英语、韩语可以另外取。
- [0024](0024-audio-sources.md) 的其余决定不变：原版音效照用，BGM 可替换，普通攻击和命中音效仍然空着。

## 理由

固定提交、核对哈希、存进自己的素材仓库，做法同 [0019](0019-operator-spine-source.md)：来源消失或出错时不影响我们。语音的规则照数据来，数据没写的明确标成推断，以后有了证据再改。

## 后果

- 素材仓库多出约 170 MB 的语音文件。页面只加载这一局双方干员的台词。
- 要跟进来源仓库的更新，新干员的语音要重新取。
- 触发时机等推断可能与游戏里不完全一样。
