# 0002 仓库划分：引擎、平台、素材各自独立

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q2, Q22, Q67

## 背景

引擎要被多个平台复用，平台含服务器和页面，素材有独立的版权状态。三者的许可、发布节奏和体积都不同。

## 决定

| 仓库 | 内容 | 许可 |
|---|---|---|
| Arknights-Universal-Engine（本仓库） | 模拟、内容、数据流程、Spine 运行时、渲染、帧同步、测试 | GPL-3.0-or-later |
| Icebreaker-Games（促融共竞） | 服务器（网关、实例、仲裁复算）、大厅和房间、页面、常规项目插件、存档；以后加账号和 mod 加载器 | AGPL-3.0-or-later |
| 素材仓库（名称待定） | 转换后的素材，按版本打标签，清单列出每个文件的哈希 | 素材版权归鹰角 |

- 平台层先放在促融共竞仓库，不单独拆出（Q22）。
- 争锋频道暂时不动。等引擎的 Spine 运行时稳定后，再把争锋频道里的 pixi-spine 换掉（Q67）。
- 争锋频道里有些代码会搬进引擎，比如 Unity UI 引擎和特效播放器。这些代码的版权属于我们，搬过来时改用 GPL 授权，在提交说明里写明出处。

## 理由

- 引擎和平台分开，别的平台也能用引擎。
- 素材版权不属于我们，必须和代码仓库分开，许可才清楚。
- 过早拆出平台层，边界还没验证，容易拆错。

## 后果

- 平台通过固定版本引用引擎（见 [0007](0007-engine-consumed-by-git-tag.md)）。
- 争锋频道在换用引擎之前，共享代码有两份，靠哈希比对防止漂移（见 [0047](0047-aue-canonical-source.md)）。
- 素材仓库的名称还没定。

## 备选方案

- 单仓库：否决，素材与代码许可不同，体积也不同。
- 现在就拆出独立的平台层仓库：否决，见理由。
