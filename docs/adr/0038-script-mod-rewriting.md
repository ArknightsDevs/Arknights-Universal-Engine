# 0038 脚本 mod：服务器在安装时改写导入路径

- 状态：已取代（被 [0058](0058-stronghold-kits-in-matches.md) 取代）
- 日期：2026-10-11
- 来源：规划讨论 Q49, Q16

## 背景

脚本 mod 同样使用兼容的导入路径（见 [0010](0010-import-mapping-table.md)），要在浏览器里的后台线程中运行。让浏览器自己改写路径既不安全也不一致。

## 决定

- 服务器安装 mod 时，用同一张映射表改写导入路径，再按内容哈希提供给客户端。
- 浏览器端从不改写。
- 脚本 mod 必须与 GPL 兼容（见 [0003](0003-licensing.md)）。
- 数据 mod 不能带脚本（见 [0039](0039-mod-assets.md)）。

## 理由

在服务器一次改写，所有客户端拿到的是同一份内容，哈希可校验。

## 后果

- 服务器承担安装时的改写职责。
- 脚本 mod 在 MVP 之后才做，晚于数据 mod。
