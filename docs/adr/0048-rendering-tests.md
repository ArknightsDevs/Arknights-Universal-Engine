# 0048 渲染测试：纯函数单测加截图回归

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q72

## 背景

渲染最容易积累没有测试的大块代码，也最依赖 three.js 的版本行为。

## 决定

- 投影、绘制排序、遮挡判断写成纯函数，做单元测试（见 [0026](0026-camera-model.md)、[0027](0027-occlusion-draw-order.md)）。
- 固定场景用 Playwright 截图做回归比对。
- three.js 固定版本，升级时以截图测试把关。

## 理由

纯函数部分能精确测；截图能抓到整体表现的回退。

## 后果

- 截图测试对环境敏感，需要稳定的运行环境和基准图。
- 截图回归测试的基础设施是单独的工作项。
