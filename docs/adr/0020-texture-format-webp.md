# 0020 贴图格式：MVP 先用 WebP，实测后再决定 KTX2

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q71

## 背景

手机显存有限。压缩贴图（KTX2）省显存，但需要转码器，增加复杂度。

## 决定

- MVP 的贴图先用 WebP。
- 在手机上实测 MVP 阵容的显存；超出预算再引入 KTX2（Basis 转码器，Apache-2.0）。
- 显存预算在渲染里程碑里定（见 [0051](0051-mvp-scope-and-milestones.md)）。

## 理由

WebP 简单，浏览器原生支持；先实测再增加复杂度，避免过早优化。

## 后果

- 手机端显存可能超预算，需要及时实测。
- 若引入 KTX2，素材仓库和 mod 素材格式（见 [0039](0039-mod-assets.md)）要相应调整。

## 备选方案

- 一开始就上 KTX2：否决，等实测证明需要再做。
