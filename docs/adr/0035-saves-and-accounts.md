# 0035 存档本地优先，账号可选且认证可插拔

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q7, Q18, Q23

## 背景

局域网和自建服务器是主要场景。很多开服的人不需要账号；有的想接入自己的 SSO。

## 决定

- 存档默认存在本地。以后可选服务器账号。
- 认证方式可插拔：无认证、密码、通用 OIDC（附常见服务的预设）。主机可以接入自己的 SSO。
- 首次登录时，玩家选择上传本地存档，还是用服务器上的存档。
- 账号放在平台仓库的 `accounts` 包，MVP 之后做（见 [0051](0051-mvp-scope-and-milestones.md)）。

## 理由

- 本地优先，不依赖服务器，隐私和运维成本最低。
- 可插拔认证，让不同规模的主机各取所需。

## 后果

- 本地存档在换设备时不能漫游，要靠账号功能解决。
- 首次登录的存档选择要处理冲突。
- 认证插件的接口要保持稳定。
