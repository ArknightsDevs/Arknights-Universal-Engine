# 0066 转身的过渡：4 帧内压扁再展开，骨架在最窄帧换

- 状态：已采纳
- 日期：2026-10-20
- 来源：实机录像数帧（寒克 https://github.com/user-attachments/assets/809cafc7-0b68-4d5b-a445-d50038d92f05 ；新能 https://github.com/user-attachments/assets/a80c8bf5-3f83-42b9-a41d-5b38d0f1a63b ）；帧率为游戏的 30 帧 / 秒
- 前序：[0064](0064-operator-facing-toward-target.md)

## 背景

[0064](0064-operator-facing-toward-target.md) 让模型朝攻击目标，但换正/背、换左右时是瞬切。实机里换面有一段过渡：模型压扁成侧影再展开，骨架在最窄的一帧换掉，而攻击动画本身不被打断。

## 决定

- 一次「侧或镜像」的变化算一次转身，从实机逐帧数出长度为 **4 帧**：30 帧 / 秒下 4/30 ≈ 0.1333 s 游戏时间。
- 宽度按 `|1 - 2k|`（`k` 为 smoothstep），高度取 `2 - 宽度`：最窄帧宽度为 0，两端回到 1。
- 骨架与镜像在**最窄帧**（`t >= 0.5`，第 2 帧）换，之前仍显示旧的侧；片段按当前显示的侧取。
- 转身与攻击片段并行，不打断片段播放。
- 仅显示：不影响 `dir`、范围、索敌、伤害。

## 参考帧位

第 0 帧开始收窄，第 2 帧最窄并在这一帧换骨架与镜像，第 4 帧恢复原宽度。

## 后果

- `render/figure.js` 的图多一个 `turn` 状态；`clipAt` 多一个可选的侧参数；`poseFigure` 负责画过渡。
- 关掉过渡只需让 `TURN_FRAMES` 为 0（一处改动）。
