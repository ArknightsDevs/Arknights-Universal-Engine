# 0036 干员 box：手动录入，可选导入两种格式，不接第三方账号

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q8, Q19, Q39

## 背景

玩家要用自己的干员练度对战（见 [0016](0016-arbitrary-operator-levels.md)）。自动获取练度需要接入第三方账号，涉及用户凭据，有合规风险（鹰角用户协议 §6.2）。

## 决定

- box 手动录入。
- 可选手动导入，只支持两种格式：
  - [MAA](https://github.com/MaaAssistantArknights/MaaAssistantArknights)「干员识别」导出的 OperBox JSON，包括一图流增强版；
  - 我们自己的存档格式。
- 导入在本地完成。
- 潜能编号统一换算（森空岛是 0–5，MAA 是 1–6）。
- 不接森空岛，也不经手任何凭据。

## 理由

不经手凭据，合规风险最小；两种格式覆盖了常见的现成导出。

## 后果

- 玩家要手动操作一次。
- 导入格式只有两种，其他来源需要先转换。
- 导入进度可以和其他功能穿插进行，不阻塞 MVP。
