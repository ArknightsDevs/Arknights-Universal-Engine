# 0024 音频：原版音效照用，缺的先空着，BGM 可替换

- 状态：已取代（被 [0061](0061-voices-and-battle-music-source.md) 取代）
- 日期：2026-10-11
- 来源：规划讨论 Q69

## 背景

战斗里有界面音效、技能和装置音效、普通攻击和命中音效、干员语音、BGM。原版音频的版权归鹰角；部分音频我们拿不到。

## 决定

- 能拿到的原版音效照原版用，由维护者放进素材仓库（见 [0018](0018-asset-repository-and-hosting.md)）。
- 战斗 BGM 默认用原版战斗曲，开服的人可以换成自己提供的文件。
- 拿不到的（普通攻击和命中音效、干员语音、促融共竞自己的 BGM）先空着，不用别的东西顶替。
- MVP 之后从公开来源补缺，记录来源并校验哈希，做法同 [0019](0019-operator-spine-source.md)。

## 理由

不编造音效；缺的先空着，比用错的东西好。

## 后果

- MVP 里普通攻击和命中没有声音，干员没有语音。
- 补音频要先找到可靠的公开来源。
