# 0025 渲染：原版样式的真 3D，战斗只用 three.js

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q44, Q58, Q63

## 背景

原版战斗是 3D 场景：地形有高度，单位是立在场景里的卡片，地形能挡住单位。Stronghold 的做法是 three.js 只画棋盘，Pixi 画单位并叠在上面，所以单位不会被地形遮挡。我们要的是原版样式。

## 决定

- 战斗画面是原版样式的真 3D，体现遮挡。
- 战斗渲染只用 three.js（MIT），不再用 Pixi。
- 材质和光照按原版的表现还原，不另外做 PBR 和实时阴影。
- 模拟语义不变；只有将来的漂航模式按官方常数做物理。
- 镜头见 [0026](0026-camera-model.md)，遮挡与绘制顺序见 [0027](0027-occlusion-draw-order.md)，Spine 见 [0028](0028-own-spine-runtime.md)。

## 理由

- 遮挡是原版观感的核心，2D 叠加做不到。
- 一套渲染后端，比 three.js 加 Pixi 两套更好维护。

## 后果

- 特效播放器要从 Pixi 移植到 three.js（见 [0023](0023-operator-effects-and-player.md)）。
- three.js 固定版本，升级以截图测试把关（见 [0048](0048-rendering-tests.md)）。
- 手机性能和显存是风险，要实测并设预算。
