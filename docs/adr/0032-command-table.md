# 0032 指令表：哪些操作走帧同步

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q30, Q52

## 背景

不是所有操作都要进模拟。进模拟的必须确定、可复算；纯表现的不必。合作模式的暂停、倍速、请求费用规则照 [PRTS](https://prts.wiki/w/促融共竞)。

## 决定

| 指令 | 规则 |
|---|---|
| 部署 | 干员、地块、朝向 |
| 撤退 | — |
| 技能开 / 关 | — |
| 倍速 | 双方都打开才变 2 倍，每人一盏指示灯 |
| 暂停 | 一方申请，队友同意后才暂停；任一方都能恢复，恢复后约 1 秒冷却 |
| 请求费用 | 队友可给 0–15 费；冷却 15 秒；自己费用满或队友失去指挥时不能请求；队友已离开时自动通过 |

- 不走帧同步的：标记、表情。战斗中只有 3 个固定的图片表情。
- 合作模式没有慢放：选中或拖动干员不减速。原先设想的"协商慢放"已删除。
- 输入延迟见 [0030](0030-input-delay-and-catchup.md)。

## 理由

只有影响模拟状态的操作才进帧同步；标记和表情不影响模拟，不必占用封口流程。

## 后果

- 标记和表情走另外的通道，不进状态哈希。
- 暂停和请求费用有玩家之间的协商流程，要在协议里表达（版本化，见 [0046](0046-versioned-interfaces.md)）。
