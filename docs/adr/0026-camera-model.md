# 0026 镜头：社区模型 + 每关镜头表 + 截图校验

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q53

## 背景

要复现原版的俯视角。我们只依据公开来源取值。

## 决定

- 基础镜头取自社区模型 [Arknights-Tile-Pos](https://github.com/yuanyan3060/Arknights-Tile-Pos)（MIT，MAA 也在用）：
  - 透视镜头，垂直视野 40°，绕 X 轴倾斜 30°；
  - 默认位置 (0, −4.81, −7.76)；
  - 画面从 16:9 变到 4:3 时，镜头偏移 (0, −1.4, −2.8)，过渡 0.2 秒。
- 每关的位置用 [ArknightsGameResource](https://github.com/yuanyan3060/ArknightsGameResource) 的 `map.json`（AGPL-3.0）里的镜头表，含普通视角和选中视角。构建时拉取并提取，注明出处。例如：

| 关卡 | 普通视角 | 选中视角 |
|---|---|---|
| 主线 01-07 | (0, −4.81, −7.76) | (0.598, −5.31, −8.642) |
| act1multi_01 | (0, −6.1, −9.76) | (0.945, −6.6, −10.612) |
| act2multi_10 | (0, −6.6, −10.63) | (1.096, −7.1, −11.469) |
| act1multi_fortress_01 | (−5, −9.1, −9.76) | (−3.979, −9.6, −11.48) |

- `map.json` 里有 3139 关的镜头，其中合作关卡 64 关。
- 坐标：一格 = 1 个单位。地图以原点为中心：x = 列 − (宽−1)/2，y = 行 − (高−1)/2。地面在 z = 0，向上是 −Z，高台高 0.2–0.4，以关卡数据为准。
- 校验：把地块网格投影到官方截图上，比较拟合结果。
- 选中干员时视角偏 10°：合作模式里是否还偏，PRTS 没写，先按偏来做，登记为推断。

## 理由

两个来源都是公开的，数值可复核，每关镜头不用猜。

## 后果

- 选中视角的数值依赖 `map.json`，要跟随其更新。
- 推断项要登记，找到证据再改（见 [0043](0043-ci-gates-and-registry.md)）。
- 投影、坐标换算写成纯函数并单测（见 [0048](0048-rendering-tests.md)）。
