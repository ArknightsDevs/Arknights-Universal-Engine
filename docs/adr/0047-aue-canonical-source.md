# 0047 AUE 是共享代码的正本

- 状态：已采纳
- 日期：2026-10-11
- 来源：规划讨论 Q72, Q22, Q67

## 背景

争锋频道和 AUE 共享一部分代码：一致性检查（simcheck）、UI 引擎、特效播放器。两份拷贝会漂移。

## 决定

- AUE 是共享代码的唯一正本。
- 争锋频道以后改为引用 AUE 的包；在那之前，CI 比对共享文件的哈希（`tools/shared-parity.mjs`）。
- 争锋频道暂时不动，等引擎的 Spine 运行时稳定后再换（见 [0002](0002-repository-split.md)）。

## 理由

单一正本，修复只做一次；哈希比对在迁移完成之前防止漂移。

## 后果

- 迁移前要在两边同步改动，有额外成本。
- 争锋频道换用引擎的 Spine 运行时，是穿插进行的工作，不阻塞主线。
