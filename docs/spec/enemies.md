# 敌人

### 出怪-1 出怪

关卡的出怪列表给出每个敌人的出现时间（秒）、种类和路线。出现时间按 时间-2 换算成帧，到那一帧时，敌人在路线起点出现，生命为满。同一帧出现的按列表顺序。

- 来源：数据：level.waves[].fragments[].actions[]（时间的展开方式为推断 INF-0007）

### 移动-1 移动

敌人依次走向路线上类型为 `MOVE` 的检查点，最后走向终点。两点之间走直线，每帧前进 `moveSpeed ÷ 30` 格；一帧内到达一个点后，剩余的距离继续沿下一段走。其他类型的检查点（等待等）在骨架中忽略。

- 来源：推断 INF-0004

### 目标-1 到达目标点

敌人到达路线终点后离场（不算阵亡），所属玩家的生命减 1，最低为 0。双人时，终点在地图左半边（列 × 2 < 宽）的属于玩家 0，其余属于玩家 1；单人时都属于玩家 0。

- 来源：推断 INF-0006
