# 时间

时间一律用整数帧表示，倒计时都是整数，所以不会因为浮点误差多走或少走一帧（见 ADR 0011）。

### 时间-1 帧率

战斗模拟每秒 30 帧。

- 来源：[PRTS「游戏数据基础」oldid=440563](https://prts.wiki/index.php?title=%E6%B8%B8%E6%88%8F%E6%95%B0%E6%8D%AE%E5%9F%BA%E7%A1%80&oldid=440563)：「战斗计时每游戏帧更新一次（+0.033）」（INF-0001 已证实）

### 时间-2 秒换算成帧

数据里以秒为单位的时长 `s`，换算成帧数 `f`：

```
f = 四舍五入(s × 30)，0.5 进位
```

- 乘法按 数值-1 在十进制上精确计算，不经过浮点乘法。所以 0.1 秒是 3 帧（浮点相乘得 3.0000000000000004）；0.05 秒是 1.5 帧，进位成 2。
- 定义域：有限且 ≥ 0 的秒数，其他输入报错。
- 结果单调不减，并且和 `s × 30` 相差不超过半帧。

- 来源：推断 INF-0002
