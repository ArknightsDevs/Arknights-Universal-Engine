# 装置

关卡预部署的装置单位：在场的时机、属性，以及它们与阻挡、敌我攻击的关系和在场效果。

### 装置-1 装置单位

关卡的预部署单位（波次-6）有装置记录（关卡-6）且给出所在格时，它生效期间是场上的一个装置单位（单位种类 `DEVICE`，不属于任何玩家，`owner` 为 −1）：站在所在格（高度取地块的），朝向取数据的，属性取记录的（属性-1），生命为满。不隐藏的从战斗开始（第 0 帧，指令之前）就在场；隐藏的在 `ACTIVATE` 动作执行时出现，`WITHDRAW` 动作执行时离场。生命归 0 的装置和其他单位一样在帧末离场（伤害-9）。装置不进行普通攻击，不移动。

- 来源：数据：level.predefines（position、direction、hidden、alias）与 character_table 的装置记录（关卡-6）；PRTS「作战机制」oldid=433935 小队动作指令表（ACTIVATE、WITHDRAW，见 波次-1）

### 装置-2 阻挡与被攻击

装置默认算我方单位（敌方装置见 装置-3）：

- **阻挡**：阻挡数大于 0 的装置和干员一样阻挡敌人（阻挡-1、阻挡-2），被它阻挡的敌人攻击它（敌人攻击-1）。
- **被选中**：远程敌人和攻击干员一样选中范围内可以选中的装置（敌人攻击-1，按 索敌-5 的顺序，嘲讽等级取装置的）。
- **占格**：干员不能部署在有装置的格子上（部署-1）。

- 来源：数据：城防路障 trap_097_hstone「可以阻挡多名敌人」，阻挡数 20；装置被敌人选中、占格为推断 INF-0148

### 装置-3 阵营与免疫

内容给每种官方装置一份说明；关卡里有没有说明的装置时，这一关暂不支持。说明可以写：

- **敌方装置**：干员像对待敌人一样选中它（索敌-3，嘲讽等级取装置的；装置没有路线，路径距离为 0），普通攻击、溅射、连锁与范围天赋里的「敌人」都包括它；它不阻挡敌人，敌人不选中、不攻击它；被打倒时和其他单位一样离场（装置-1）。
- **免疫**：装置对列出的异常状态免疫（状态-7）。
- 治疗只选干员，装置不会被治疗。

官方装置：城防路障（trap_097_hstone）是我方装置，免疫晕眩、冻结、寒冷、沉默、沉睡；山海密语仪（trap_096_gflag）是敌方装置（嘲讽等级 −1）。

- 来源：[PRTS「城防路障」oldid=417801](https://prts.wiki/index.php?title=%E5%9F%8E%E9%98%B2%E8%B7%AF%E9%9A%9C&oldid=417801)「阵营=我方」「持有禁疗、孤立、晕眩免疫、冻结免疫、寒冷免疫、沉默免疫、沉睡免疫」；[PRTS「山海密语仪」oldid=337660](https://prts.wiki/index.php?title=%E5%B1%B1%E6%B5%B7%E5%AF%86%E8%AF%AD%E4%BB%AA&oldid=337660)「阵营=敌方」「嘲讽等级=-1」；数据：character_table trap_096_gflag tauntLevel −1。敌方装置的路径距离与「敌人」范围包括它为推断 INF-0150

### 装置-4 在场效果

装置的说明可以给出它在场时给所有敌人（中立单位除外）的属性修正：每个装置在每个敌人身上一个 Buff，随装置离场消失，所以几个装置的修正叠加（加算的相加，乘算的相乘，属性-2）。山海密语仪：攻击速度 +25（直接加算）、移动速度 ×1.15（最终乘算），数值取它天赋的 blackboard（attack_speed、move_speed）。

- 来源：[PRTS「山海密语仪」oldid=337660](https://prts.wiki/index.php?title=%E5%B1%B1%E6%B5%B7%E5%AF%86%E8%AF%AD%E4%BB%AA&oldid=337660)「在场时，所有敌方单位的攻击速度+25，移动速度最终提升至115%（可无限叠加）」；数据：character_table trap_096_gflag 隐藏天赋 blackboard move_speed 1.15、attack_speed 25；几个装置的移动速度相乘为推断 INF-0150
