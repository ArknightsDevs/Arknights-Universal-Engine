# 装置

关卡预部署的装置单位：在场的时机、属性，以及它们与阻挡、敌人攻击的关系。

### 装置-1 装置单位

关卡的预部署单位（波次-6）有装置记录（关卡-6）且给出所在格时，它生效期间是场上的一个装置单位（单位种类 `DEVICE`，不属于任何玩家，`owner` 为 −1）：站在所在格（高度取地块的），朝向取数据的，属性取记录的（属性-1），生命为满。不隐藏的从战斗开始（第 0 帧，指令之前）就在场；隐藏的在 `ACTIVATE` 动作执行时出现，`WITHDRAW` 动作执行时离场。生命归 0 的装置和其他单位一样在帧末离场（伤害-9）。装置不进行普通攻击，不移动。

- 来源：数据：level.predefines（position、direction、hidden、alias）与 character_table 的装置记录（关卡-6）；PRTS「作战机制」oldid=433935 小队动作指令表（ACTIVATE、WITHDRAW，见 波次-1）

### 装置-2 阻挡与被攻击

装置算我方单位：

- **阻挡**：阻挡数大于 0 的装置和干员一样阻挡敌人（阻挡-1、阻挡-2），被它阻挡的敌人攻击它（敌人攻击-1）。
- **被选中**：远程敌人和攻击干员一样选中范围内可以选中的装置（敌人攻击-1，按 索敌-5 的顺序，嘲讽等级取装置的）。
- **占格**：干员不能部署在有装置的格子上（部署-1）。

- 来源：数据：城防路障 trap_097_hstone「可以阻挡多名敌人」，阻挡数 20；装置被敌人选中、占格为推断 INF-0148
