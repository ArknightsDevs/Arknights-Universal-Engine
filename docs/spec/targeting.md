# 索敌

实现见 `packages/sim/src/targeting.js`。

### 索敌-1 攻击范围的格

攻击范围由一组偏移给出，以面朝右为准，随朝向旋转（方向-2）。

- 攻击距离属性为 n 时，每个格向正前方拉伸 n 格：偏移 (行, 列) 同时覆盖 (行, 列 + 1) … (行, 列 + n)。
- 落在地图外的格去掉。
- 单位的任何一格（体积-1、体积-2）在范围内，就算在范围内。

- 来源：[PRTS「攻击范围」oldid=421062](https://prts.wiki/index.php?title=%E6%94%BB%E5%87%BB%E8%8C%83%E5%9B%B4&oldid=421062)：「每1点攻击距离属性会令组成其攻击范围的方块向正前方拉伸1格」；数据：range_table.grids

### 索敌-2 可选性

另一方的单位在以下情况下不能被选中：

- 生命为 0；
- 无法选中（`untargetable`）；
- 隐匿（`stealth`）。被阻挡时解除隐匿的规则在 M3。
- 沉睡；
- 迷彩（`camou`），除非这次攻击无视迷彩；
- 空中单位，除非这次攻击能选中空中单位。近战干员不能选中空中单位。

- 来源：[PRTS「术语释义」oldid=440223](https://prts.wiki/index.php?title=%E6%9C%AF%E8%AF%AD%E9%87%8A%E4%B9%89&oldid=440223) 隐匿「不阻挡时不成为敌方攻击的目标」、迷彩「不阻挡时不成为敌方普通攻击的目标」；[PRTS「异常效果」oldid=440606](https://prts.wiki/index.php?title=%E5%BC%82%E5%B8%B8%E6%95%88%E6%9E%9C&oldid=440606) 隐匿「无法被不同阵营选中」；沉睡不可选、近战不能选中空中单位为推断 INF-0021

### 索敌-3 干员的目标顺序

候选按它们出现的顺序排列，然后用稳定的插入排序依次比较：

1. **阻挡**：近战干员正在阻挡的敌人在前；远程干员不优先。
2. **特殊优先级**：技能、天赋给出的优先级，小的在前（M3）。
3. **仇恨值**：从高到低，比对精度 0.1。比较的是「仇恨值 × 10 向零取整」后的整数，所以相差不到 0.1 的值可能算作相等。
   - 敌人的仇恨值 = 10⁸ × 嘲讽等级 − clamp(路径距离, −10⁸, 10⁸)，路径距离见 索敌-6；
   - 也就是嘲讽等级高的在前，同等级时路径距离短的在前。
4. **最早出现**：以上都相等时，保持原来的顺序。

排好后取前 n 个（目标数，至少 1 个）。


- 来源：[PRTS「索敌的概念」oldid=376233](https://prts.wiki/index.php?title=%E7%B4%A2%E6%95%8C%E7%9A%84%E6%A6%82%E5%BF%B5&oldid=376233)：「阻挡（近战限定）→特殊优先级→第二优先级→仇恨值（更容易被攻击→剩余路程最短→不容易被攻击）→最早出现」；[PRTS「仇恨」oldid=429076](https://prts.wiki/index.php?title=%E4%BB%87%E6%81%A8&oldid=429076)：敌人类仇恨值公式，「仇恨降序」的比对精度为 0.1，比较时「乘以比对精度的倒数，后转为整型」，排序是「稳定性排序（逻辑类似插入排序法）」；向零取整为推断 INF-0019

### 索敌-4 嘲讽等级

嘲讽等级是属性（属性-3，−2 到 2）。等级越高越容易被选中，比任何路径距离或部署先后的差别都优先，因为仇恨值里它乘的系数远大于另一项的范围。

- 来源：[PRTS「仇恨」oldid=429076](https://prts.wiki/index.php?title=%E4%BB%87%E6%81%A8&oldid=429076)：「仇恨值越高越容易被选中」；[PRTS「数值范围」oldid=439605](https://prts.wiki/index.php?title=%E6%95%B0%E5%80%BC%E8%8C%83%E5%9B%B4&oldid=439605) TAUNT_LEVEL −2–2

### 索敌-5 敌人的目标顺序

敌人选择我方单位时，同样用稳定的插入排序：

1. **阻挡**：阻挡它的单位在前；
2. **仇恨值**：从高到低，比对精度 0.1。
   - 我方单位的仇恨值 = 3 × 10⁸ × 嘲讽等级 + clamp(创建时间 × 1000 + 同帧部署数, −3 × 10⁸, 3 × 10⁸)；
   - 创建时间是单位创建时的战斗时间（秒，= 帧号 / 30）；同帧部署数是它在那一帧里第几个创建（从 1 起）；
   - 也就是嘲讽等级高的在前，同等级时后部署的在前。
3. **最早出现**：保持原来的顺序。

被阻挡的近战敌人只攻击阻挡它的单位、远程敌人的候选范围，在 M3 的敌人行动里实现。

- 来源：[PRTS「索敌的概念」oldid=376233](https://prts.wiki/index.php?title=%E7%B4%A2%E6%95%8C%E7%9A%84%E6%A6%82%E5%BF%B5&oldid=376233)：「阻挡→特殊优先级→仇恨值（更容易被攻击→第二优先级→最后部署的目标→不容易被攻击）→最早出现」；[PRTS「仇恨」oldid=429076](https://prts.wiki/index.php?title=%E4%BB%87%E6%81%A8&oldid=429076)：角色类仇恨值公式、同帧部署数

### 索敌-6 路径距离

敌人的路径距离（单位：格）用于仇恨值（索敌-3）：

- **能到达时**：如果敌人所在格（寻路-3）能走到当前目标路径点（它正在走、或接下来要走的那段移动的终点格），路径距离 = 终点距离 + 修正值。
  - **终点距离**：从所在格起，依次到每个后续路径点的流场距离（寻路-1，即按格计的寻路步数）之和，一直算到终点。经过「出现」时，下一段从出现的位置算起，传送之间的距离不计；巡逻点只算一遍。
  - **修正值**：从敌人坐标指向所在格中心的向量，在它前进方向（指向它正在走向的点）上的投影，可以为负。
- **到不了或在地图外时**：从当前坐标到当前目标路径点的直线距离。

- 来源：[PRTS「仇恨」oldid=429076](https://prts.wiki/index.php?title=%E4%BB%87%E6%81%A8&oldid=429076)：「若所在地块可到达目标路径点，则路径距离为：终点距离（以所在地块的坐标为起点，直接串联所有路径点的到终点曼哈顿寻路距离之和，“传送门”之间的距离除外）+修正值」，修正值为「自身所在具体坐标→当前地块中心」的向量在前进方向上的投影（可负）；「若所在地块不可到达目标路径点，或自身处于地图外，则路径距离为：当前坐标至当前目标路径点的直线距离」；巡逻点只算一遍为推断 INF-0029
