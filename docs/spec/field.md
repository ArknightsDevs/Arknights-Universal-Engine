# 地图、部署、费用

### 地图-1 坐标

地块按"路线坐标"存放：第 0 行是离镜头最近的一行，第 0 列是最左一列。关卡文件的 `mapData.map` 从最上一行开始列出，路线的位置（起点、检查点、终点）已经是第 0 行在下。所以：

```
tiles[r] = mapData.map[高 − 1 − r]
```

- 来源：数据：level.mapData.map、level.routes[].startPosition（出怪起点必须落在出怪点地块上，测试据此核对）

### 地图-2 封闭的格边

关卡可以封闭一些格边（`blockEdges`）：每条给出一格（行列同路线坐标，第 0 行在下）、这格的哪一边（UP 朝行 + 1，RIGHT 朝列 + 1，DOWN，LEFT）和它挡谁（WALK_ONLY 挡地面单位，FLY_ONLY 挡空中单位，ALL 都挡，NONE 不挡）。一条格边把它两侧的格隔开，两个方向都隔开；数据里每条边只从一侧列出。

- **寻路**：被挡的单位不能在这两格之间走（寻路-1），视线也不能跨过它（寻路-2）；斜着走一步时，交于那个角的四条格边都不能对它封闭。
- **滑行**：失衡滑行的地面单位要跨过封闭的格边时停下（位移-3）。

- 来源：[PRTS「玉门天灾工事」oldid=440587](https://prts.wiki/index.php?title=%E7%8E%89%E9%97%A8%E5%A4%A9%E7%81%BE%E5%B7%A5%E4%BA%8B&oldid=440587)「每个玉门天灾工事的四个边缘具有“可进出性”配置，不可进出的边缘上会存在？宽度的物理碰撞“墙体”，并在敌人寻路时将此地块与相应的周边地块之间的路径视为不可通行」；数据：level.mapData.blockEdges（pos、direction、blockMask）。方向的取法由数据核对：按上述取法，IG-10 匪帮集会与 IG-S-2 爬高上低里每一处玉门天灾工事与普通地块（云梯除外）的交界都有一条 WALK_ONLY 的边，每条地面路线仍然走得通（测试据此核对）。两侧都隔开、FLY_ONLY/ALL/NONE 的含义、斜走与滑行的处理为推断 INF-0149

### 部署-1 可部署地块

近战干员只能部署在可部署类型为 `MELEE` 的地块上，远程干员只能部署在 `RANGED` 的地块上，两类都可部署在 `ALL` 的地块上；特性允许时，近战干员也可以部署在 `RANGED` 的地块上（职业-10）。地图外不能部署。

- 来源：数据：level.mapData.tiles[].buildableType、character_table.position

### 部署-2 部署条件

满足以下全部条件才能部署，否则这条指令被忽略，状态不变：

- 干员存在，座位存在；内容给出了卡组时（同步-9），干员在这名玩家的卡组里；
- 这名玩家场上没有同一名干员；
- 这名玩家没有失守（合作-4）；
- 这名玩家已部署的数量小于关卡的 `characterLimit`（每名玩家分别计算）；特性不计入部署数量的干员（职业-13）不受这条限制，也不计入已部署的数量；
- 干员不在再部署时间内（部署-3）；
- 费用不低于干员现在的部署费用（部署-3）；
- 地块满足 部署-1，且上面没有任何玩家的干员。

部署后扣除现在的部署费用并记在干员身上（撤退-1 返还时用），干员面朝指令给出的方向。

- 来源：每名玩家分别计算为推断 INF-0041

### 部署-3 再部署惩罚与再部署时间

每名玩家的每名干员有一张「卡」，记录再部署惩罚层数（0–2）和可以再次部署的帧。

- **部署费用**：⌊初始部署费用 × (1 + 0.5 × 再部署惩罚层数)⌋。初始部署费用是干员数据的 `cost`。也就是第二次部署要 1.5 倍、之后 2 倍。
- **离场**：干员撤退或生命归 0 离场时，卡的惩罚加 1 层（最多 2 层）；从离场那一帧起，经过再部署时间（干员数据 `respawnTime` 秒，没有时 60 秒，按 时间-2 换算成 n 帧），第 离场帧 + n 帧起才可以再部署。生命归 0 不返还费用。

- 来源：[PRTS「部署费用」oldid=434779](https://prts.wiki/index.php?title=%E9%83%A8%E7%BD%B2%E8%B4%B9%E7%94%A8&oldid=434779)：「部署费用（属性）=(初始部署费用+基础费用增减)×费用倍率+实时费用增减」，再部署惩罚「通常在干员每次退场（包括撤退、被击倒）后会累积一层再部署惩罚（上限两层），每层为待部署区的自己提供0.5的额外费用倍率……第二次部署所需的费用为一开始的1.5倍（之后向下取整），第三次则变为一开始的2.0倍」；[PRTS「数值范围」oldid=439605](https://prts.wiki/index.php?title=%E6%95%B0%E5%80%BC%E8%8C%83%E5%9B%B4&oldid=439605)：RESPAWN_TIME 再部署时间，下限 0，未给出时 60；数据：character_table 各阶段 respawnTime（处决者 18 秒、行商 25 秒、情报官 35 秒，多数 70 秒）；计时的起止为推断 INF-0042

### 部署-4 常驻天赋

干员数据带 `talentBb`（常驻天赋的 blackboard，干员-6）时，干员部署时就带着一个 Buff：键 `talent`，没有持续时间（不会结束），修饰器按 技能-5 的属性键表从 `talentBb` 换算。它和其他 Buff 一样计入属性（属性-1），部署时的生命按带着它的最大生命值算满。

- 来源：天赋常驻生效、和技能的属性加成同样换算为推断 INF-0088；数据：character_table 的 talents（干员-4）

### 部署-5 在场天赋

每帧在干员的回合之前（帧-1 第 7 步，和 职业-13 的光环一起），每个在场、干员数据带 `fieldTalents` 的干员，对其中每一条（职业或势力、blackboard），给场上这个职业、或有这个势力（干员-10）的每个干员（任何玩家的，包括它自己）一个键为 `field:<它的 id>:<序号>` 的 Buff，修饰器按 技能-5 的属性键表从 blackboard 换算。来源不在场时去掉这些 Buff。

- 来源：干员-9；作用于所有玩家的干员为推断 INF-0094

### 部署-6 范围天赋

和 部署-5 同时，每个在场、干员数据带 `rangeTalents` 的干员，对其中每一条（对象、修饰器），给有一格在它攻击范围（攻击-1，含攻击距离）里的每个对象一个键为 `range:<它的 id>:<序号>` 的 Buff，带这些修饰器：对象为敌人时是场上的敌人（不含中立单位），为友方时是场上的干员（任何玩家的，包括它自己；只对远程干员的只给远程位的干员）。离开范围的、来源不在场的，去掉这个 Buff。

- 来源：干员-11；对任何玩家的干员、对范围内所有敌人（包括飞行的、隐匿的）生效为推断 INF-0095

### 部署-7 时间天赋

干员数据带 `timedTalents`（时间天赋，干员-13）时，干员部署时对其中第 i 条加一个键为 `timed:<i>` 的 Buff：

- 「部署后N秒内」（`during`）：带它的修饰器，持续 `seconds` 秒；
- 「在战场停留N秒后」（`after`）：没有结束时间，每 `seconds` 秒（不受衰减率影响）触发；第一次触发时带上它的修饰器，此后不变；
- 「每在场上停留N秒」（`stack`）：同样每 `seconds` 秒触发，每次升一级（最多 `max` 级），修饰器为它的修饰器 × 级数。

- 来源：干员-13；第一次在部署后一个间隔、级数乘修饰器为推断 INF-0103

### 部署-8 部署时的天赋

干员数据带 `deployTalents`（部署天赋，干员-14）时，干员部署时（特性生效之后、被动技能发动之前）按顺序：

- **技力**：区间 [`sp[0]`, `sp[1]`) 里的一个整数——区间不止一个数时抽一个随机数（随机-1），取 `sp[0]` + ⌊随机数 × (`sp[1]` − `sp[0]`)⌋——加到技能的技力上（不超过上限，技能-2）；
- **治疗**：治疗场上每名干员（任何玩家的，包括自己）`value` 点生命，或 `scale` × 自身攻击力（治疗规则同 伤害-11，产生 `heal` 事件）；
- **护盾**：获得这么多层护盾（伤害-8，键为 `deployShield` 的 Buff）。

- 来源：干员-14；区间的上界不含、随机数的抽取方式为推断 INF-0104

### 部署-9 移动

内容可以让在场的干员「移动」到另一格（`moveOperator`）：

1. 目标格不是它能部署的格子（部署-1），或已有别的干员：它被撤退（撤退-1），不再处理。
2. 否则它放开阻挡的敌人（阻挡-3），站到目标格（朝向不变），然后：
   - **一般**：同一个单位在那里重新部署——不带任何 Buff、技能状态（运行中的技能结束），技力清空，部署时的效果再次生效（特性、部署天赋、被动技能、召唤物卡，部署-2、部署-8、召唤-4，`deploy` 事件带 `move`），不积累再部署惩罚，不返还费用；部署完成后流失生命（伤害-10），使生命比例与移动前相同。
   - **保留**（内容的特殊设置）：Buff、技能状态和生命都保留，只发 `deploy` 事件（带 `move`），部署时刻改为现在。Stronghold 的移动都是这样（DIF-0034）。

- 来源：[PRTS「术语释义」oldid=440223](https://prts.wiki/index.php?title=%E6%9C%AF%E8%AF%AD%E9%87%8A%E4%B9%89&oldid=440223) 移动（ba.addash）：「不退场，以当前血量在目标位置部署」「本质上为一次特殊的撤退-再部署行为」「①尝试判断目标位置是否可部署 ②若目标地块不合法，强制撤退自身并不再处理 ③撤退自身，在目标地块再部署，完成移动」「除非具有特殊设置，否则执行移动行为时：不会继承任何Buff、技能状态，不再被视为手动部署；因移动撤退时不会积累再部署惩罚；可以通过移动行为多次触发部署时触发的效果（包括且不限于：岁怒、初始技力增加）；部署完成后，立刻流失一次生命值以匹配移动前的生命比例；部署时将清空技力」；强制撤退按一般撤退处理、移动时放开阻挡与朝向不变为推断 INF-0145

### 撤退-1 撤退

玩家只能撤退自己的干员。撤退后干员离场（部署-3），并返还费用：

返还量 = ⌊min(这次部署消耗的费用 × 返还倍率, 初始部署费用)⌋

返还倍率由分支特性给出（职业-1），默认 50%，冲锋手 100%。返还后的费用不超过上限（费用-1）。

- 来源：[PRTS「部署费用」oldid=434779](https://prts.wiki/index.php?title=%E9%83%A8%E7%BD%B2%E8%B4%B9%E7%94%A8&oldid=434779) 撤退返费：「返费量=⌊min(部署费用（属性）×返还倍率,返还上限)⌋」，返还上限「通常等同于单位的基础部署费用」，返还倍率「大部分召唤物、装置、特种-行商分支通常为0%，先锋-冲锋手为100%，其他大部分干员为50%」，「当前费用到达最大费用上限时……溢出部分将会被丢弃」

### 费用-1 费用

每名玩家各有一份费用。开局为关卡的 `initialCost`，每隔 `costIncreaseTime` 秒（按 时间-2 换算成帧）加 1，不超过 `maxCost`。

- 来源：数据：level.options.initialCost、costIncreaseTime、maxCost；每名玩家分开计算为推断 INF-0008
