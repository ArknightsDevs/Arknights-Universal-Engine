# 战斗循环与同步

### 帧-1 一帧内的顺序

每一帧按固定顺序执行：

1. 这一帧的指令，按服务器封口时的顺序；
2. 费用增长；
3. 出怪；
4. 敌人移动、到达目标点；
5. 干员攻击；
6. 移除生命归零的单位。

第 F 帧的指令在执行第 F 帧时生效，执行完帧号加一。

- 来源：推断 INF-0010

### 随机-1 随机数

对局的随机数用 mulberry32，32 位状态存在世界状态里，随快照保存。初始状态取种子的低 32 位。只用 `Math.imul`、移位和异或，所有引擎结果相同。

- 来源：设计决定，见 [ADR 0011](../adr/0011-numerics-integer-frames.md)

### 同步-1 状态哈希

状态哈希是 32 位 FNV-1a，按以下顺序处理一串数字，每个数字取 IEEE-754 小端字节：

1. 帧号、随机状态、下一个单位编号、下一个出怪序号、玩家数；
2. 每个玩家：生命、费用、费用计时、已部署数，以及每个已部署干员的编号字符串；
3. 每个单位：编号字符串，以及各数值字段。

字符串按长度和 UTF-16 码元记入。−0 与 0 不同；所有 NaN 按同一个值处理。

- 来源：设计决定，见 [ADR 0031](../adr/0031-desync-recovery.md)

### 同步-2 快照

快照是世界状态的完整深拷贝，装在第 1 版快照外壳里（ADR 0053），不含当帧的表现事件。从任意一帧的快照恢复后继续执行，每一帧的状态哈希都与不中断执行时相同。外壳格式不对，或数据的帧号与外壳不一致时，拒绝恢复。

- 来源：设计决定，见 [ADR 0053](../adr/0053-interface-schemas.md)
