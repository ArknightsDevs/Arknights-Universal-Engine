# 攻击与伤害

### 攻击-1 干员攻击

- **攻击范围**：干员的攻击范围由一组偏移给出，以面朝右为准：列是前方，行是左侧。面朝上、左、下时，偏移随之旋转。
- **出手**：攻击冷却结束、范围内有敌人时，攻击最早出现的那个敌人。敌人所在的格取其位置四舍五入。
- **冷却**：攻击后等待攻击间隔（`baseAttackTime` 秒，按 时间-2 换算成帧）再攻击。部署后立即可以攻击。
- **骨架里没有的**：攻击前摇、阻挡、敌人攻击、技能。它们在 M2–M3 加入。

- 来源：数据：character_table.phases[].rangeId、range_table.grids、baseAttackTime；目标选择、冷却起点和前摇的省略为推断 INF-0005

### 伤害-1 物理伤害

物理伤害的基础值 = 攻击力 − 目标防御力。

- 来源：[PRTS「伤害分类」oldid=433934](https://prts.wiki/index.php?title=%E4%BC%A4%E5%AE%B3%E5%88%86%E7%B1%BB&oldid=433934)

### 伤害-2 最低伤害

一次物理伤害至少为攻击力的 5%，即 `max(攻击力 − 防御力, 攻击力 × 0.05)`。

- 来源：[PRTS「游戏数据基础」oldid=440563](https://prts.wiki/index.php?title=%E6%B8%B8%E6%88%8F%E6%95%B0%E6%8D%AE%E5%9F%BA%E7%A1%80&oldid=440563)：物理、法术伤害公式都取 max(…, 0.05 × A)（INF-0003 已证实）
