# 攻击

### 攻击-1 干员攻击

- **攻击范围**：干员的攻击范围由一组偏移给出（索敌-1）。
- **出手**：攻击冷却结束、有候选（索敌-2、职业-1）时，攻击按官方顺序排在前面的目标（索敌-3），目标数和伤害次数见 职业-3，每下造成攻击力 × 攻击力倍率的伤害，类型是干员的伤害类型（伤害-6、伤害-7）。近战干员还可以选中自己阻挡的敌人（阻挡-4）。治疗干员的普通攻击改为治疗友方（职业-2）。
- **冷却**：出手后等待攻击间隔（属性-5，整数帧）再攻击。部署后立即可以攻击。
- **无法行动**：晕眩、冻结、沉睡、浮空时既不攻击，冷却也不减少（状态-5）。
- **还没有的**：攻击前摇（M3c）。技能见 skills.md，分支特性见 traits.md。

- 来源：数据：character_table.phases[].rangeId、range_table.grids、baseAttackTime；冷却起点、无法行动时冷却不减、前摇的省略为推断 INF-0005
