# 合作规则

促融共竞的双人规则。实现见 `packages/sim/src/coop.js`。单人时这些规则退化为普通的目标点。

### 合作-1 目标点的归属

合作关卡的目标点（`tile_end_cooperate`）在地块的 blackboard 里写明属于哪一方（`side`）：

| side | 属于 |
|---|---|
| `Side_A` | 座位 0 |
| `Side_B` | 座位 1 |
| `Shared` | 双方 |

没有写明的目标点：单人时属于座位 0；双人时，在地图左半边（列 × 2 < 宽）的属于座位 0，其余属于座位 1。

- 来源：数据：level.mapData.tiles[].blackboard 的 `side`；battle/cooperate_battle_table.json 的 `endTileInfo`（MY_SIDE「我的目标点」、MATE_SIDE「协作者目标点」、SHARED「共同目标点」）；[PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839)「双方玩家拥有各自的目标生命值（互不影响）」；哪一方对应哪个座位为推断 INF-0051，没有写明时按地图左右为推断 INF-0006

### 合作-2 敌人进入目标点与共同敌手

敌人走到路线终点时离场（不算阵亡），按目标点扣生命（每次 1 点，最低 0）：

- **一般敌人**：目标点所属的每一方扣 1 点（合作-3 的情况除外）。
- **共同敌手**：进入任何目标点，所有没有失守（合作-4）的玩家都扣 1 点。哪些敌人是共同敌手由关卡数据给出：符文 `env_gbuff_new_with_verify` 中 `key` 为 `cooperate_enemy_side_shared` 的那一条，`enemy` 列出这些敌人。

- 来源：[PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839)：「蓝色目标点为己方目标点。敌方进入时会扣除自己的目标生命值」「墨绿色目标点为协作者目标点。敌方进入时会扣除协作者的目标点」「共同敌手，这种敌人进入任一目标点会扣除双方的生命值」；battle/cooperate_battle_table.json：SHARED「敌方进入后会同时扣除双方目标生命值」；数据：level.runes

### 合作-3 失守的目标点

一方生命为 0（合作-4）时，进入他的目标点的敌人改由协作者扣 1 点生命；同时他的复活倒计时重新从 30 秒开始。双方都失守时不再扣。

- 来源：battle/cooperate_battle_table.json：MY_SIDE「生命值归零时，进入的敌人会出现在协作者目标点」，MATE_SIDE「生命值归零时，进入的敌人会出现在我的目标点」；[PRTS「罗德岛促融共竞」oldid=431336](https://prts.wiki/index.php?title=%E7%BD%97%E5%BE%B7%E5%B2%9B%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=431336)「该玩家的目标点将成为新的侵入点或传送通道，敌方选手将向剩下的一方目标点发起进攻」；[PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839)「这期间敌人进入该方目标点时，倒计时会被重置为30s」；「出现在协作者目标点」按立刻扣协作者生命计为推断 INF-0052

### 合作-4 失守与复活

- **失守**：一方的生命降到 0 时失守，产生表现事件 `down`（事件第 6 版）：
  - 不能部署（部署-2）；
  - 他在场的干员全部停止行动：不攻击、不发动技能、不阻挡，也不能被敌人选中（异常状态 `sidelined`），生命保持不变；
  - 记一次失守（`downs`，常规项目结算时用）；
  - 开始 30 秒（900 帧）的复活倒计时。
- **复活**：倒计时每帧减 1；到 0 时复活，生命回到关卡的生命上限，干员恢复行动，产生表现事件 `revive`。敌人进入他的目标点时倒计时重新开始（合作-3）。

- 来源：[PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839)：「当一方的目标生命值降至0时，该方将进入死亡状态，此时该玩家将不能部署自己的干员，所属的场上干员全部失去功能」「若另一方能在30s内维持该方目标点没有敌人，在倒计时结束后该玩家即可复活并恢复指挥权」「若玩家进入过死亡状态不少于两次，该玩家在最终结算时获取的"嘉奖印章"减少1枚」；[PRTS「罗德岛促融共竞」oldid=431336](https://prts.wiki/index.php?title=%E7%BD%97%E5%BE%B7%E5%B2%9B%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=431336)「该玩家失去指挥权；该玩家的所有干员立刻停止行动（表现上同保全派驻被击倒求援中的干员）」；停止行动的具体内容、复活时的生命为推断 INF-0053
