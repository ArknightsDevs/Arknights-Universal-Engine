# 堡垒守御

促融共竞的堡垒守御：防御阶段与休整阶段轮替、场上的设施和修建它们的建筑工、守住的波次。关卡带全局 Buff `cooperate_fortress_global_buff` 时是堡垒守御关（守御-1）。目标点、失守与复活、费用请求同两人对局（合作-1…合作-5）；没有比赛阶段（合作-6）。

### 守御-1 赛制

关卡全局 Buff `cooperate_fortress_global_buff` 的 blackboard 给出：休整时长 `rest_time`、防御时限 `wave_time`、最后一波的防御时限 `wave_time_last`（秒），每次休整回复的目标生命 `life_point`。内容把它整理成关卡的 `fortress`。

- **第一波**：战斗开始就是第 1 波的防御阶段（波次照常从第 0 帧开始，波次-2）。
- **之后每一波**：上一波的防御阶段结束后先休整（守御-2），休整结束时下一波开始（`preDelay` 照常），开始它的防御阶段。
- **状态**：堡垒守御的进度（阶段、当前波次、阶段到时的帧、守住的波数、伤害记录、各座位的「休整完毕」和建筑工卡、看守的出怪，这一波要出的敌人数——不计不拦波次的——和其中已经离场的）、设施的等级和建筑工的工作是状态的一部分，进入快照和状态哈希（快照第 17 版）。
- **防御阶段**：从这一波开始计时。这一波的出怪做完、它的敌人都离场时结束；或者到了时限（最后一波用 `wave_time_last`，其余用 `wave_time`）结束——这时这一波还没出的不再出，场上属于这一波的敌人直接离场（不扣生命，不算击倒）。防御阶段和休整开始、最后一波的防御阶段结束时产生表现事件 `fortress`（事件第 11 版，`wave` 为波次序号——休整的是它之后那一波，`phase` 为 0 防御、1 休整、2 结束，`until` 为这一阶段到时的帧）。
- **守住**：一次防御阶段从开始到结束，两名玩家都没有失守过（合作-4），这一波算守住，守住的波数加 1。
- **结束**：最后一波的防御阶段结束时比赛结束（`result` 为 1）；所有玩家同时失守时比赛也结束（`result` 为 0，结束-1）。两种情况都按守住的波数记录。
- **嘉奖印章**：守住 3、5、7 波分别得 1、2、3 枚（每名玩家相同，合作-6 的失守扣减照常）。
- **最后一波**：最后一波（试炼丰碑）的敌人损失的生命总和记为它的伤害记录。

- 来源：[PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839) 堡垒守御：「其中第一波次直接进入防御阶段，之后的波次是先进入休整阶段，再进入防御阶段」「通过击倒全部敌方选手或坚持到一定时间即视为成功抵御该波次。坚持至一定时间后剩余的敌人会自动死亡并退场」「每个防御阶段双方均未沦陷时即视为抵御成功，完成比赛后将会记录本次比赛抵御成功的最高波次数」；[PRTS「促融共竞/01」oldid=430486](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E/01&oldid=430486)「坚守3波次 / 坚守5波次 / 坚守7波次」「此时本次比赛的结果将在3枚嘉奖印章评价之外额外记录对试炼丰碑的伤害量」；数据：level.globalBuffs `cooperate_fortress_global_buff`（IG-DF-1：rest_time 65、wave_time 120、life_point 3、wave_time_last 300）。blackboard 各键的含义、离场的敌人不算击倒、全员失守时结束为推断 INF-0203

### 守御-2 休整阶段

- **开始时**：两名玩家的生命各加 `life_point`（不超过上限）；每个设施回到它到过的最高等级（守御-3）；按建筑工具间发放建筑工（守御-5）；产生 `fortress`（`phase` 为 `rest`）。
- **期间**：不出怪。撤退的干员再部署时间直接归零。只有休整期间能部署建筑工（守御-4）。
- **结束**：`rest_time` 秒到时结束；或者每名玩家都发出「休整完毕」（指令 `{ type: 'rest' }`，协议第 10 版，同步-3），立即结束。休整结束后的帧里一个玩家的「休整完毕」不再算数。
- `rest_add` 暂不使用。

- 来源：[PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839)「目标生命值+3（不会超过上限），此期间将获得维护设施，并给予较长的休息时间」「此阶段撤退干员时再部署时间直接清零」「双方玩家也可以提前发出休整完毕信号。当双方均表示休整完毕后，将立即进入下一防御阶段」；数据：rest_time、life_point（IG-DF-2 为 5，与 PRTS 的 +3 不同，按数据）；指令的形式为推断 INF-0203

### 守御-3 设施

关卡预部署的建筑工具间（`trap_205_mufrfm`）、临时休息舱（`trap_206_mufrbk`）、液压式高台（`trap_207_mufrwl`）、混凝土路障（`trap_208_mufrst`）、便携健身架（`trap_209_mufrbs`）是设施：装置单位（装置-1），另有等级 0…3、进度（SP）和到过的最高等级。

- **等级**：开局 0 级（原料箱）：无敌、不能被选中、不阻挡。1…3 级时阻挡数 3、可以被敌人攻击（装置-2）。各等级的数值取记录的第 k 个天赋（k 为等级）：`cost` 为从这一级升到下一级要的进度，`max_hp` 为生命上限的加成（2 即 +200%）。
- **修建**：建筑工每次攻击使设施进度 +`sp`（高级建筑工 +`sp2`）；进度达到当前等级的 `cost` 时，设施升到到过的最高等级 +1 级（最多 3 级），进度清零，生命回满。超出的进度丢弃。满级（3 级）的设施不再受修建。
- **击毁**：受到致命伤害时不离场：这次伤害取消，进度清零，回到 0 级（生命回满）。到过的最高等级保留，下次休整开始时回到那一级（守御-2）。
- 设施不进行普通攻击，免疫晕眩、冻结、浮空、沉睡，不受治疗（装置-3）。等级变化时产生表现事件 `facility`（事件第 11 版，`id`、`level`）。

- 来源：[PRTS「建筑工具间」oldid=424753](https://prts.wiki/index.php?title=%E5%BB%BA%E7%AD%91%E5%B7%A5%E5%85%B7%E9%97%B4&oldid=424753) 等五个设施页面：「受到来自[[设施建筑工]]/[[高级设施建筑工]]的伤害时，取消此伤害并+1SP/+3SP」「受到足以致命的伤害时，取消当次伤害、清空自身SP并切换为初始模式」「进入休整阶段时，将自身切换为曾达到过的最高等级的模式」「每次切换为不同模式后，回复100%生命值」「技能触发时，将自身切换为曾达到过的最高等级+1级的模式（最高切换至3级模式）」，初始模式「无敌」「不可选中」「不可阻挡」，阻挡数 3，晕眩、冻结、浮空、沉睡免疫，禁疗；[PRTS「促融共竞/01」oldid=430486](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E/01&oldid=430486)「溢出丢弃」；数据：character_table 各设施的四个（混凝土路障五个）天赋

### 守御-4 建筑工

设施建筑工（`trap_166_muwork`）与高级设施建筑工（`trap_202_muworkg`）是两名玩家各自待部署区里的计数卡：

- **张数**：开局按关卡自带的装置卡（关卡-7）的张数；休整开始时按建筑工具间加（守御-5）；坍塌的杂物堆每次放出一名高级建筑工（守御-6）。部署一名用掉一张。
- **部署**：只能在休整阶段部署，费用取记录的（普通 0、高级 5），不占可部署人数；只能部署在没满级的设施周围 4 格（上下左右相邻）里可部署的格子上，朝向自选。
- **工作**：部署 1 秒后开始，每秒攻击一次面前一格的没满级的设施（守御-3 的修建）。普通建筑工攻击 5 次、高级 18 次后离场；到了记录天赋的 `duration`（6 秒、20 秒）也离场。
- **返还**：离场时一次也没攻击过的，待部署区的这种建筑工加回一张。
- 建筑工不能被敌人选中，不阻挡，玩家不能撤退它，不回收费用；不占卡组的再部署（同一张卡可以同时有几名在场）。

- 来源：[PRTS「设施建筑工」oldid=398756](https://prts.wiki/index.php?title=%E8%AE%BE%E6%96%BD%E5%BB%BA%E7%AD%91%E5%B7%A5&oldid=398756)「自身仅能部署于未满级<设施>的周围4格」「普通攻击能且仅能攻击未满级的<设施>」「登场6秒后强制撤退」「退场时若未持有开工标记，则向待部署区添加1个设施建筑工」「不可选中」「不可阻挡」；[PRTS「高级设施建筑工」oldid=398813](https://prts.wiki/index.php?title=%E9%AB%98%E7%BA%A7%E8%AE%BE%E6%96%BD%E5%BB%BA%E7%AD%91%E5%B7%A5&oldid=398813)；[PRTS「促融共竞」oldid=377839](https://prts.wiki/index.php?title=%E4%BF%83%E8%9E%8D%E5%85%B1%E7%AB%9E&oldid=377839)「普通的<设施建筑工>可为目标设施每次补充1点进度（SP），补充5次后下班」「<高级设施建筑工>可为设施每次补充3点进度，维护18次后下班」「如果提前维护完成，建筑工会提前下班」；数据：character_table 建筑工的记录（攻击间隔 1.0、范围 1-1、费用 0/5、天赋 duration 6/20）、level.predefines.tokenCards。卡按玩家各自计、开始攻击的时刻为推断 INF-0204

### 守御-5 设施的效果

设施在 1 级以上时：

- **建筑工具间**：每次休整开始时，每名玩家的设施建筑工加等级数（记录天赋的 `cnt`）张；几个建筑工具间相加。
- **临时休息舱**：每名玩家的可部署人数加等级数（部署-2）；3 级时所有干员的再部署时间减少 20%。
- **便携健身架**：两名玩家的所有干员生命上限 +25% / +30% / +50%，攻击力 +0 / +15% / +20%，技力自然回复速度 +0 / +0 / +1（数值取记录的天赋）；几个健身架叠加（属性-2）。
- **液压式高台**：所在格变为可部署远程干员的高台（地图-1），并参与敌人的寻路：类障碍物地块，代价 1,000（寻路-1）。2、3 级生命上限 +200%；3 级时部署在上面的干员攻击速度 +50。回到 0 级时，部署在上面的干员被强制击倒（不算撤退）。
- **混凝土路障**：阻挡敌人（不改变寻路，装置-2）。2、3 级生命上限 +200%；3 级时被击毁的瞬间对周围 1 格（半径 1.0）的地面敌人造成 20000 物理伤害。

- 来源：[PRTS「建筑工具间」oldid=424753](https://prts.wiki/index.php?title=%E5%BB%BA%E7%AD%91%E5%B7%A5%E5%85%B7%E9%97%B4&oldid=424753)、[「临时休息舱」oldid=424752](https://prts.wiki/index.php?title=%E4%B8%B4%E6%97%B6%E4%BC%91%E6%81%AF%E8%88%B1&oldid=424752)、[「便携健身架」oldid=424759](https://prts.wiki/index.php?title=%E4%BE%BF%E6%90%BA%E5%81%A5%E8%BA%AB%E6%9E%B6&oldid=424759)、[「液压式高台」oldid=428398](https://prts.wiki/index.php?title=%E6%B6%B2%E5%8E%8B%E5%BC%8F%E9%AB%98%E5%8F%B0&oldid=428398)、[「混凝土路障」oldid=424762](https://prts.wiki/index.php?title=%E6%B7%B7%E5%87%9D%E5%9C%9F%E8%B7%AF%E9%9A%9C&oldid=424762)；数据：各设施天赋的 cnt、value_char、max_hp、atk、attack_speed、damage。效果作用于两名玩家、几个设施相加、高台的寻路代价、路障爆炸只伤地面敌人为推断 INF-0205

### 守御-6 坍塌的杂物堆

关卡的坍塌的杂物堆（`trap_203_mufrprn`）不能被选中、不受伤害、不阻挡。关卡的分支 `mufrprn_branch` 是看守它的敌人，一段一批，走关卡的额外路线（`extraRoutes`，多半在它旁边原地等待）：每次防御阶段开始时，分支里与这一波序号相同的那一段出怪（段不够时用最后一段，同 波次-2 的片段）。它周围（范围 `x-2`）的敌人嘲讽等级 −1。防御阶段开始 5 秒起每 2 秒检查一次：周围没有敌人时，每名玩家的高级设施建筑工加一张，这次防御阶段不再检查。

- 来源：[PRTS「坍塌的杂物堆」oldid=380508](https://prts.wiki/index.php?title=%E5%9D%8D%E5%A1%8C%E7%9A%84%E6%9D%82%E7%89%A9%E5%A0%86&oldid=380508)「击杀周围看守的敌人时，可以解救被困的高级设施建筑工」，防御阶段开始后在预设路径上出现看守的敌人，第 5 秒起每 2 秒检查范围内是否还有敌人，没有则向待部署区添加 1 个高级设施建筑工，「每个防御阶段仅能生效1次」；「※技能范围内的所有敌方单位（无视无法选择）嘲讽等级-1」「※防御阶段开始后以关卡预设路径召唤一批敌人」；数据：level.branches `mufrprn_branch`（IG-DF-1 十四段，每段一到两名看守，路线指向 level.extraRoutes，检查点等待 99999 秒）、skill_table sktok_mufrprn_1（range_id x-2）。一次防御阶段用与波次序号相同的那一段、每名玩家各得一张为推断 INF-0204
